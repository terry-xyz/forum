# Comment Timeline
## Topic
The post detail page presents flat comments in the order they were created, oldest first.

## JTBD
- When I open a post, I want to read comments in the order they were posted so I can follow the discussion naturally.

## Acceptance Criteria
- The post detail page shows comments ordered by creation time from oldest to newest.
- The earliest comment on that post appears first.
- Later comments appear after earlier comments on the same post.
- The ordering stays stable across reloads of the same post detail page.
- All viewers of the same post detail page see the same oldest-first comment order.

## Out Of Scope
- Creating comments.
- Comment deletion.
- Comment reactions.
- Nested reply support.
