# Post Detail Reading
## Topic
Visitors can open a post detail page to read a forum post.

## JTBD
- When I open a post link, I want to read the full post without signing in so I can follow forum discussions from shared links.

## Acceptance Criteria
- An anonymous visitor can open a valid post detail page without signing in.
- A signed-in user can open the same post detail page.
- The post detail page shows the requested post's full content.
- The post detail page shows the comments attached to that post.

## Out Of Scope
- Creating a post or comment.
- Comment ordering or reply structure.
- Editing or deleting content.
